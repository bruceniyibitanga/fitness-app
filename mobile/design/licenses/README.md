# Font licences

The apps bundle two fonts from [Google Fonts](https://github.com/google/fonts), both under the SIL Open Font License 1.1, which allows bundling them in an app:

- **Archivo** (`res/font/archivo.ttf`, variable width and weight): [Archivo-OFL.txt](Archivo-OFL.txt)
- **JetBrains Mono** (`res/font/jetbrains_mono.ttf`, variable weight): [JetBrainsMono-OFL.txt](JetBrainsMono-OFL.txt)

The fonts are bundled rather than downloaded at runtime so the apps make no network request to show text, and work offline from the first launch.

The open source licences screen (Phase 7) must list both.
